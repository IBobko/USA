# DS-160: правило заполнения поля State/Province

## 1) Общее правило

В поле **State/Province** указывается административный регион адреса (штат, область, край, республика, город федерального значения и т.д.).

- Если у страны есть региональное деление, поле нужно заполнять значением региона.
- `Does Not Apply` используется только когда регионального уровня действительно нет или форма это прямо допускает.

## 2) Частный случай: адрес в Москве (РФ)

Москва — город федерального значения и одновременно регион.

Поэтому для адреса в Москве:
- **City:** `Moscow`
- **State/Province:** `Moscow`

`Does Not Apply` для этого случая не используется.
